# Contribuer

Node.js 22.15+ ou 24 LTS, sans dépendances. Copier `.env.example` en `.env` pour un appel réel à Gemma, puis `npm run dev`. `npm run check` ne nécessite aucune clé.

Les contributions utiles améliorent un contrôle mesurable, l’accessibilité, l’export ou la documentation. Décrire le problème, la modification et sa vérification dans la pull request. Ne pas publier de clés ou d’images sans droits de redistribution.

Préserver ces règles : Gemma reste le modèle d’annotation hébergé ; aucune validation automatique ; exclusions et corrections traçables ; sources proches conservées dans la même partition ; exemple synthétique toujours identifié.

Pour une erreur de modèle, fournir une description reproductible et seulement des images partageables. Pour une clé divulguée, la révoquer auprès du fournisseur et ne jamais la recopier dans une issue.
